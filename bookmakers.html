Expanded odds coverage — optional Krok connector ready

Krok Odds publishes a multi-bookmaker direct-scrape feed for Sportsbet, TAB, Unibet, BetRight, PointsBet, Ladbrokes and other operators. The scanner can now read compatible prices from that feed when you provide an authorized Krok API key in Vercel, choose a sport and enable Extra bookmaker feed. No bookmaker is counted unless it actually supplies a valid quote.

Free tier: advertised at 50 API requests per month. The extra feed is manual-only; repeated scans consume quota. Get a free Krok API key, then add it as the server-side Vercel environment variable KROK_ODDS_API_KEY (Production). Do not paste API secrets into the website or GitHub.

Connection status: code ready — not live until a key is configured and valid prices return. Existing SockOdds is rate-limited and subject to its own plan restrictions.

Licensing: Krok's terms require a custom commercial licence for a competing arbitrage or odds product. Contact Krok before using that data in a public commercial scanner. The Odds API independently permits derived values and user-facing applications subject to its terms; no provider permits unlimited free calls.

New third odds provider — The Odds API (free Starter)

A separate server-side THE_ODDS_API_KEY can be used to retrieve Australian head-to-head odds for one selected sport. Supports mapped AFL, NRL, NBA, NHL, NFL, MLB, EPL soccer and Big Bash cricket fixtures. The Starter account advertises 500 credits/month; one AU region × one head-to-head market normally costs one credit. The scanner suppresses stale prices and excludes exchange markets.

Create free API key · Official API documentation. Add the key in Vercel Production and redeploy. On the Scanner, choose a supported sport, switch on The Odds API and press Scan once. This source is optional and inactive without a valid key; do not add the secret to GitHub.
