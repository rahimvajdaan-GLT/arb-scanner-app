# Arb Scanner App

A lightweight manual sports arbitrage calculator for 2-way and 3-way markets.

## Current V1 features

- Manual event and market entry
- 2-way arbitrage calculator
- 3-way arbitrage calculator
- Decimal odds input
- Automatic stake split
- Arbitrage index
- Guaranteed payout estimate
- Estimated profit
- ROI percentage
- Responsive desktop/mobile interface

## Important

Only compare the exact same event, market, line, and settlement rules across bookmakers. This app performs mathematical calculations only. Real-world betting outcomes can differ because odds may move, stakes can be rejected or limited, fees or commissions may apply, and bookmaker rules may differ.
