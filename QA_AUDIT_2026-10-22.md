## Major defects fixed
1. NBA/MLB filter key mismatch and misleading league-specific selections.
2. Unnecessarily narrow default category discovery for Neds/Ladbrokes; categories rotate without requesting all at once.
3. Incorrect or unsafe team matching (e.g., New York teams sharing only city tokens).
4. Source market contamination: half-time/special-market Entain prices could enter full-match comparisons. Source parsing now requires a labelled and complete full-match market, market-entrant association, and price sanity checks.
5. Previously invisible same-best-book comparisons and missing single-source fixture information.
6. Duplicate odds API request per page scan.
7. Auto production odds probes that increased request rates. The probe is now manual-only.
8. Old product branding across help, legal, contact, and account pages.
9. Exaggerated language around guaranteed returns; the UI now identifies *theoretical* arbitrage and limited feed coverage.

## Remaining limits and validation needed
- **SockOdds:** Live scan returned HTTP 429. The free quota or request rate can block data. Code cannot bypass account allowances.
- **Neds / Ladbrokes:** The current production window also returned HTTP 429, and these provider contracts need fresh real-response validation before describing their odds as verified. Source-specific price parsing now rejects ambiguous records rather than producing fake positive arbs.
- **Coverage:** A valid arbitrage comparison requires at least two accessible bookmaker markets on the same fixture with compatible outcome, period and settlement conditions. One-source fixtures are displayed for transparency but not claimed as arbitrage.
- **Market types:** Only match-winner is enabled. Spreads/totals are deliberately disabled until market/line/period matching has been tested.
- **Authentication:** Login page and endpoint exist and pass static checks, but an actual authenticated login/logout session was not exercised because no test account was supplied.
- **Price execution:** Mathematical return is a quote, not accepted bets or a guaranteed payoff. Limits, fees, rules and changes are not independently verified.

## How to repeat the tests
- Source regression tests run automatically on each push: `node --test tests/*.test.cjs`.
- Desktop/mobile Chromium smoke is in `.github/workflows/browser-smoke.yml` and can be run manually in GitHub Actions.
- Manual production odds diagnostics live in `.github/workflows/probe-odds.yml`. This is intentionally no longer triggered on every code push.
- In a browser, visit the scanner, refresh, run Scan Opportunities, review *Odds Comparison* cards and *Feed diagnostic*. If only one bookmaker returns prices, look for **single-bookmaker fixtures**, not positive arbitrage.

## Acceptance criteria
- No false-positive arbs from incompatible or unrelated markets.
- No claim of “0 games” if accessible single-source fixtures exist.
- No repeated diagnostic request from the same page scan.
- Viewport widths 390 and 1440 have no horizontal overflow.
- Any source that is blocked must be clearly indicated as degraded, not represented as confirmed zero market availability.
